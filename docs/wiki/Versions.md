# Версии и границы обещаний

Последний подтверждённый публичный снимок до подготовки интеграции **5.7.5**: Desktop **5.7.2**, Web CLI **5.6.12**, resource **2.2.3**, managed-access SDK **1.0.4**. Сверяйте актуальные данные перед публикацией: они могут измениться независимо друг от друга.

**5.7.5 — частный integration candidate**: он не считается установленным, прошедшим live acceptance или опубликованным релизом. **5.7.4 не выпускался.** Номер в `package.json`, успешная локальная сборка или публикация отдельного компонента не подтверждают выпуск и приёмку Desktop/Web.

Проверяемые источники публичных версий:

| Поставка | Публичная версия | Источник |
| --- | --- | --- |
| Desktop | `v5.7.2` | [Release feed](https://update.anubis.locker/data/anubis-release.json), поле `release.tag_name`, не `version` верхнего уровня |
| Web CLI | `anubis-web@5.6.12` | [Метаданные latest](https://npm.anubis.locker/anubis-web/latest) |
| Ресурсы | `@ai-security-tool/resource@2.2.3` | [Метаданные latest](https://npm.anubis.locker/@ai-security-tool/resource/latest) |
| Managed-access SDK | `@ai-security-tool/managed-access@1.0.4` | [Метаданные latest](https://npm.anubis.locker/@ai-security-tool/managed-access/latest) |

Таблица — контрольный снимок, не обещание неизменности `latest` и не версия минимальной поддержки. Версии Desktop, renderer, Web CLI, ресурсов и SDK независимы; перед объявлением релиза обновите её по живым метаданным и проверенному runtime.

| Область | Что можно утверждать |
| --- | --- |
| Обычные подключения | Настройка зависит от протокола, платформы, сборки и доступности целевой службы |
| Исправления Windows machine host | Описан контракт исходников; нужен совместимый GUI, broker/helper и engine |
| Старые результаты QA | Не подтверждают текущий установленный runtime или новый сценарий |
| Standalone Web | Отдельный пакет и профиль; версия renderer не заменяет версию обёртки |
| PRO-меню | Community, Plugin Store, Automation, DLL Scanner, CVE Scanner, Crypto Miner, Browser Control — семь объявленных заглушек |
| AI по умолчанию | В исходниках предусмотрен stub, а не обещание работающей модели |

Перед обращением запишите версии GUI, службы и Web-обёртки, тип установки и режим работы. Для machine host не смешивайте новый GUI со старым helper. Поддержка протокола не означает сертификацию всех серверов, физических serial-устройств или всех Windows-сессий.

Плановая приёмка должна отдельно подтвердить установку, UAC, обновление, сохранение данных, вход в нужный workspace, терминал и отзыв доступа. До этого не представлять частные исправления как публично доступные.
