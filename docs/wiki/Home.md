# 🛡️ Anubis-Security-Tool: руководство

Anubis объединяет терминалы, подключения к серверам и работу с файлами. Эти Wiki-ready страницы помогают выбрать правильный режим, настроить доступ и понять его границы. Они хранятся в `docs/wiki`; наличие исходников здесь не означает, что отдельная GitHub Wiki уже опубликована.

**Сначала проверьте [статус версии](Versions.md): подтверждённый Desktop — 5.7.2; 5.7.5 — частный integration candidate, а 5.7.4 не выпускался.**
